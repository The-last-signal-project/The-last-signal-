# 🧪 プロトタイプを試（ため）す

## 📋 必要（ひつよう）な環境（かんきょう）

以下（いか）が必要（ひつよう）です。

* 🐍 **Python 3.14**
* 🦀 **Rust と Cargo**
* 🌿 **Git**

---

## 📥 1. リポジトリをクローンする

```bash
git clone https://github.com/DDCoder23/The-last-signal-.git
cd The-last-signal-
```

---

## 🐍 2. Python の依存関係（いぞんかんけい）をインストールする

**プロジェクトのルートディレクトリ**から実行（じっこう）します。

```bash
pip install -r requirements.txt
```

---

## 🦀 3. Rust サーバーを起動（きどう）する

最初（さいしょ）のターミナルを開（ひら）き、サーバーディレクトリに移動（いどう）します。

```bash
cd server_rust
```

次（つぎ）にサーバーを起動（きどう）します。

```bash
cargo run --locked
```

### 🧹 クリーンビルド — 任意（にんい）

`cargo clean` は**サーバーを起動（きどう）するたびに実行（じっこう）する必要（ひつよう）はありません**。

完全（かんぜん）にクリーンな状態（じょうたい）から再（さい）ビルドしたい場合（ばあい）は、以下（いか）を実行（じっこう）してください。

```bash
cargo clean
cargo run --locked
```

このターミナルではサーバーを起動（きどう）したままにしてください。

---

## 🎮 4. クライアントを起動（きどう）する

**2つ目（ふたつめ）のターミナル**を開（ひら）き、プロジェクトのルートディレクトリに戻（もど）ります。

```bash
cd The-last-signal-
```

次（つぎ）のコマンドでクライアントを起動（きどう）します。

```bash
python -m client_python.main
```

クライアントがローカルサーバーに接続（せつぞく）します。
