## 🌍 概要（がいよう）

**The Last Signal Online** は、プレイヤー同士（どうし）が協力（きょうりょく）し、探索（たんさく）し、絶（た）えず変化（へんか）する世界（せかい）で生（い）き残（のこ）ることを目指（めざ）す、ポストアポカリプス世界（せかい）を舞台（ぶたい）としたサバイバルMMORPGです。

このプロジェクトは、以下（いか）の要素（ようそ）を組（く）み合（あ）わせた没入感（ぼつにゅうかん）のあるマルチプレイヤー体験（たいけん）の実現（じつげん）を目指（めざ）しています。
