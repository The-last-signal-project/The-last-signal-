# 04 — Chronologie

## 1. Introduction

La chronologie de **The Last Signal** présente les événements majeurs de l'univers du jeu dans leur ordre temporel.

Elle sert de référence commune pour le scénario, la construction de l'univers, les personnages, les factions et les événements rencontrés par les joueurs.

> **Principe :** la chronologie doit distinguer les événements historiques de l'univers, les événements connus des personnages et les informations révélées progressivement au joueur.

---

## 2. Époque précédant les événements du jeu

Avant le début de l'aventure, plusieurs événements ont progressivement conduit le monde vers la situation dans laquelle se déroule le jeu.

Cette période permet d'expliquer :

* l'état actuel du monde ;
* l'origine des principales factions ;
* l'apparition des conflits ;
* les changements technologiques ou scientifiques ;
* les événements ayant conduit à la situation initiale du joueur.

Les événements précis de cette période seront ajoutés au fur et à mesure de la construction du lore.

---

## 3. Événement déclencheur

L'histoire principale commence lorsqu'un événement majeur vient modifier l'équilibre du monde.

Cet événement constitue le point de départ de l'intrigue principale et doit permettre au joueur de comprendre progressivement :

1. ce qui s'est produit ;
2. pourquoi cet événement est important ;
3. quelles conséquences il entraîne ;
4. quel rôle le joueur peut jouer dans la suite des événements.

Les détails définitifs de l'événement déclencheur restent à définir dans le scénario principal.

---

## 4. Début de l'histoire

Le joueur découvre le monde dans son état actuel.

À ce stade, le joueur ne possède pas nécessairement toutes les informations permettant de comprendre la situation globale.

La narration doit donc fonctionner progressivement :

**Découverte → Questionnement → Investigation → Révélation → Compréhension → Conséquences**

Certaines informations peuvent volontairement rester inconnues afin de conserver les mystères centraux de l'univers.

---

## 5. Progression chronologique de l'histoire

### Phase I — Découverte

Le joueur découvre :

* son environnement ;
* les premières informations concernant le monde ;
* les personnages importants ;
* les premières menaces ;
* les premiers indices concernant le mystère principal.

---

### Phase II — Investigation

Le joueur commence à rechercher les causes des événements.

Il découvre progressivement que les informations disponibles au début de l'histoire ne représentent qu'une partie de la réalité.

Les différentes factions peuvent également présenter des versions différentes des mêmes événements.

---

### Phase III — Révélations

Les découvertes du joueur permettent de relier plusieurs événements auparavant indépendants.

Certaines révélations peuvent modifier la compréhension que le joueur avait :

* d'un personnage ;
* d'une faction ;
* d'un événement historique ;
* de la situation actuelle ;
* de son propre rôle dans l'histoire.

---

### Phase IV — Confrontation

Les conséquences des découvertes du joueur deviennent progressivement impossibles à ignorer.

Les différentes forces présentes dans le monde peuvent entrer directement en conflit.

Les choix et les actions du joueur commencent alors à avoir des conséquences importantes sur l'évolution de l'histoire.

---

### Phase V — Conséquences

Les événements précédents aboutissent à une situation dans laquelle les décisions du joueur peuvent influencer la suite du monde.

Cette phase doit permettre de montrer que les événements de l'histoire ne sont pas isolés : ils ont des conséquences sur les personnages, les factions et le monde.

---

## 6. Chronologie détaillée

| Période          | Événement                         | Importance | Informations connues du joueur   |
| ---------------- | --------------------------------- | ---------- | -------------------------------- |
| Avant l'histoire | Événements historiques antérieurs | À définir  | Inconnues au début               |
| Début            | Événement déclencheur             | Majeure    | Découverte progressivement       |
| Phase I          | Début de l'aventure               | Majeure    | Partiellement connue             |
| Phase II         | Investigation                     | Majeure    | Découvertes progressives         |
| Phase III        | Révélations                       | Critique   | Informations importantes         |
| Phase IV         | Confrontation                     | Critique   | Conséquences visibles            |
| Phase V          | Conséquences                      | À définir  | Dépend des événements précédents |

---

## 7. Chronologie et narration

La chronologie réelle de l'univers et la chronologie de découverte du joueur ne doivent pas nécessairement être identiques.

### Chronologie réelle

Elle représente l'ordre dans lequel les événements se sont réellement produits dans l'univers.

### Chronologie narrative

Elle représente l'ordre dans lequel le joueur apprend ces événements.

Cette distinction permet notamment de conserver certains mystères.

**Exemple :**

> Un événement peut avoir eu lieu avant le début du jeu, mais son existence peut n'être révélée au joueur qu'après plusieurs heures de jeu.

---

## 8. Événements futurs

La chronologie est évolutive.

Les nouveaux événements ajoutés au scénario doivent être intégrés dans ce document afin d'éviter les contradictions entre :

* le scénario ;
* le lore ;
* les quêtes ;
* les personnages ;
* les factions ;
* les dialogues ;
* les événements multijoueurs.

Tout événement important doit donc être ajouté à la chronologie lorsqu'il devient officiellement canonique.

---

## 9. Règles de cohérence

Lorsqu'un nouvel élément scénaristique est ajouté :

1. déterminer sa date ou sa période ;
2. déterminer les événements qui le précèdent ;
3. déterminer ses conséquences ;
4. vérifier qu'il ne contredit pas un événement existant ;
5. déterminer quelles informations sont connues du joueur ;
6. mettre à jour la chronologie si nécessaire.

### Statut des événements

Chaque événement peut recevoir l'un des statuts suivants :

* **Canonique** — événement officiellement établi dans l'univers ;
* **En développement** — événement prévu mais susceptible d'être modifié ;
* **À définir** — événement nécessaire mais dont les détails ne sont pas encore établis ;
* **Non canonique** — idée ou ancienne version ne faisant plus partie de l'univers officiel.
