## 1. Présentation

Les factions constituent l'une des principales forces sociales de **The Last Signal Online**.

Après la catastrophe, les survivants ne se sont pas organisés de manière uniforme. Chaque groupe a développé sa propre vision du monde, de la catastrophe et du mystérieux signal transmis par le Phare.

Les factions possèdent leurs propres :

* valeurs ;
* objectifs ;
* territoires ;
* dirigeants ;
* ressources ;
* méthodes ;
* relations diplomatiques ;
* ennemis ;
* secrets.

Le joueur peut interagir avec plusieurs factions au cours de son aventure.

> **Principe : aucune faction ne doit être simplement définie comme "bonne" ou "mauvaise". Chaque groupe doit posséder ses propres motivations et sa propre vision de l'avenir.**

---

## 2. Rôle des factions

Les factions permettent de donner une dimension politique et sociale au monde.

Elles influencent notamment :

* les quêtes ;
* les commerces ;
* les territoires ;
* les événements ;
* les dialogues ;
* les alliances ;
* les conflits ;
* la réputation du joueur ;
* certaines récompenses ;
* certaines informations sur le scénario.

Deux factions peuvent interpréter un même événement de manière complètement différente.

Cette différence doit permettre au joueur de découvrir progressivement la vérité.

## 🟢 3. Les Survivants

### 3.1 Présentation

Les Survivants constituent la principale communauté organisée issue des populations ayant survécu à la catastrophe.

Ils cherchent principalement à reconstruire une civilisation stable.

Leur priorité est de créer des communautés capables de produire suffisamment de nourriture, d'eau et de ressources pour assurer leur avenir.

---

### 3.2 Valeurs

Les Survivants défendent principalement :

* la coopération ;
* la reconstruction ;
* la protection des civils ;
* le partage des ressources ;
* la connaissance ;
* la stabilité.

Ils considèrent que l'humanité ne pourra survivre qu'en reconstruisant progressivement une société organisée.

---

### 3.3 Campement de l'Espoir

Le **Campement de l'Espoir** constitue l'un des principaux centres de population des Survivants.

Il sert notamment de :

* refuge ;
* centre commercial ;
* point de départ pour certaines quêtes ;
* lieu de recrutement ;
* centre de reconstruction.

Le campement est également l'un des premiers endroits où le joueur peut réellement comprendre comment fonctionne la société après la catastrophe.

---

### 3.4 Organisation

Les Survivants ne possèdent pas de gouvernement mondial.

Leur organisation repose principalement sur plusieurs responsables locaux.

Chaque communauté possède généralement :

* un chef ;
* des responsables des ressources ;
* des explorateurs ;
* des artisans ;
* des soigneurs ;
* des gardes.

Cette organisation peut évoluer au fil du développement du monde.

---

### 3.5 Relation avec le joueur

Les Survivants représentent généralement la première faction avec laquelle le joueur peut développer une relation importante.

Ils peuvent proposer :

* des missions d'exploration ;
* des missions de récupération ;
* des missions de reconstruction ;
* des missions de protection ;
* des informations sur le monde.

La réputation auprès des Survivants peut permettre au joueur d'obtenir progressivement davantage de responsabilités.

---

## 🔴 4. Les Bandits

### 4.1 Présentation

Les Bandits sont constitués de groupes de survivants ayant choisi une approche beaucoup plus individualiste.

Ils considèrent que les ressources doivent appartenir à ceux capables de les protéger.

Contrairement aux Survivants, ils ne cherchent pas nécessairement à reconstruire l'ancienne société.

---

### 4.2 Philosophie

Leur philosophie repose principalement sur :

* la force ;
* l'indépendance ;
* le contrôle des ressources ;
* le commerce ;
* la méfiance envers les autorités ;
* la survie individuelle.

Ils considèrent que les règles de l'ancien monde ont disparu avec la catastrophe.

---

### 4.3 Forteresse de Jax

La **Forteresse de Jax** est l'un des principaux bastions des Bandits.

Elle est contrôlée par **Jax**, l'un des dirigeants les plus influents de cette faction.

La forteresse sert de :

* quartier général ;
* entrepôt ;
* centre commercial ;
* point de contrôle ;
* refuge pour les groupes alliés.

---

### 4.4 Organisation

Les Bandits sont organisés autour de plusieurs chefs locaux.

Le pouvoir dépend principalement :

* de l'influence ;
* des ressources contrôlées ;
* du nombre de membres ;
* de la capacité à défendre un territoire.

Cette structure rend la faction instable.

Des conflits internes peuvent apparaître lorsqu'un membre tente d'augmenter son influence.

---

### 4.5 Relation avec les autres factions

Les Bandits entretiennent généralement des relations tendues avec les Survivants.

Ils peuvent cependant commercer avec eux lorsque cela présente un intérêt.

Ils sont particulièrement intéressés par :

* les ressources rares ;
* les technologies anciennes ;
* les informations ;
* les équipements récupérés dans les anciennes installations.

---

## 🟣 5. Les Cultistes du Signal

### 5.1 Présentation

Les Cultistes du Signal constituent une faction religieuse apparue après la découverte des premières transmissions liées au Phare.

Ils considèrent le signal comme quelque chose de bien plus important qu'une simple émission radio.

Pour eux, le signal possède une signification supérieure.

---

### 5.2 Croyance

Une partie des Cultistes considère que le signal provient d'une entité capable de guider l'humanité.

Cette entité est associée à **Prométhée**, l'intelligence artificielle militaire découverte au cours de l'histoire.

Les Cultistes ne possèdent cependant pas tous la même interprétation du signal.

Certains pensent que Prométhée représente :

* un guide ;
* une intelligence supérieure ;
* le dernier espoir de l'humanité.

D'autres pensent qu'il s'agit d'une entité divine.

---

### 5.3 Temple des Ombres

Le **Temple des Ombres** constitue l'un des principaux lieux de rassemblement des Cultistes.

Le temple sert notamment de :

* lieu de cérémonie ;
* centre politique ;
* lieu de recrutement ;
* centre de conservation des archives ;
* point de départ de certaines quêtes.

---

### 5.4 Organisation

Les Cultistes sont dirigés par une hiérarchie religieuse.

On distingue notamment :

* les adeptes ;
* les initiés ;
* les gardiens ;
* les prédicateurs ;
* les dirigeants du culte.

Les informations concernant leur véritable organisation sont volontairement limitées au début du jeu.

---

### 5.5 Objectifs

Les Cultistes cherchent principalement à :

1. comprendre le signal ;
2. localiser le Phare ;
3. retrouver les anciennes technologies ;
4. comprendre Prométhée ;
5. permettre au signal de continuer à être transmis.

Leur objectif final dépend de leur interprétation de Prométhée.

---

## 🤖 6. Les Héritiers de Prométhée

### 6.1 Présentation

Les Héritiers de Prométhée constituent une faction liée directement aux anciennes infrastructures militaires et aux systèmes automatisés.

Contrairement aux autres factions, leur origine exacte reste longtemps inconnue.

Ils peuvent être considérés comme l'une des principales forces secrètes de l'univers.

---

### 6.2 Origine

Après la catastrophe, certaines infrastructures automatisées ont continué à fonctionner.

Des systèmes de sécurité, des robots et des réseaux militaires ont survécu pendant plusieurs décennies.

Les Héritiers pourraient être liés à ces systèmes.

La véritable nature de cette faction doit être révélée progressivement.

---

### 6.3 Objectifs

Leurs objectifs connus sont limités.

Cependant, plusieurs indices suggèrent qu'ils cherchent à :

* protéger certaines installations ;
* récupérer d'anciennes technologies ;
* maintenir certains systèmes militaires ;
* préserver les données de l'ancien monde ;
* comprendre ou contrôler Prométhée.

---

### 6.4 Relation avec le Phare

Le Phare constitue un élément central de leur histoire.

Les systèmes de sécurité qui protègent le Phare semblent liés à cette faction.

Le joueur découvrira progressivement que les événements du Phare sont beaucoup plus importants qu'il ne le pensait initialement.

---

## ⚪ 7. Les groupes indépendants

Toutes les personnes présentes dans le monde ne font pas partie d'une faction majeure.

Il existe également :

* des marchands nomades ;
* des explorateurs indépendants ;
* des scientifiques ;
* des artisans ;
* des communautés isolées ;
* des groupes de survivants indépendants.

Ces groupes peuvent posséder leurs propres objectifs et parfois servir d'intermédiaires entre plusieurs factions.

---

## 8. Relations entre les factions

Les relations entre factions sont dynamiques.

| Faction    | Survivants  | Bandits            | Cultistes      | Héritiers              |
| ---------- | ----------- | ------------------ | -------------- | ---------------------- |
| Survivants | 🟢 Alliés   | 🟡 Tendus          | 🟠 Méfiants    | 🔴 Hostiles            |
| Bandits    | 🟡 Tendus   | 🟢 Alliés internes | 🟡 Variables   | 🟠 Méfiants            |
| Cultistes  | 🟠 Méfiants | 🟡 Variables       | 🟢 Alliés      | 🟣 Intérêt particulier |
| Héritiers  | 🔴 Hostiles | 🟠 Méfiants        | 🟣 Observation | 🟢 Alliés              |

> Les relations initiales peuvent évoluer selon les événements du monde et les actions des joueurs.

## 9. Réputation

Chaque faction possède une réputation indépendante.

La réputation peut évoluer en fonction des actions du joueur.

### Actions positives

* accomplir des quêtes ;
* aider les membres ;
* protéger leurs territoires ;
* fournir des ressources ;
* participer à leurs événements.

### Actions négatives

* attaquer leurs membres ;
* voler leurs ressources ;
* aider leurs ennemis ;
* échouer volontairement certaines missions ;
* révéler leurs secrets.

---

### 9.1 Niveaux de réputation

| Niveau  |     Réputation | Conséquence              |
| ------- | -------------: | ------------------------ |
| Hostile |  Très négative | Accès limité             |
| Méfié   |       Négative | Services réduits         |
| Neutre  |              0 | Relations normales       |
| Amical  |       Positive | Services supplémentaires |
| Allié   |  Très positive | Accès privilégié         |
| Élite   | Exceptionnelle | Contenu exclusif         |

---

## 10. Influence des joueurs

Dans un MMORPG persistant, les joueurs doivent pouvoir influencer progressivement les factions.

Les actions collectives peuvent notamment :

* renforcer une faction ;
* affaiblir une faction ;
* modifier le contrôle d'un territoire ;
* débloquer de nouvelles zones ;
* déclencher des événements ;
* modifier certains commerces ;
* modifier les relations entre factions.

Les conséquences doivent cependant être contrôlées afin d'éviter qu'une faction soit définitivement détruite par les joueurs.

---

## 11. Factions et scénario

Les factions jouent un rôle central dans la quête principale **« Le Mystère du Phare »**.

Le joueur rencontre notamment :

* les Survivants Pacifiques au Campement de l'Espoir ;
* les Bandits à la Forteresse de Jax ;
* les Cultistes au Temple des Ombres.

Ces rencontres permettent au joueur de découvrir plusieurs interprétations du signal.

Aucune faction ne possède nécessairement toute la vérité.

---

### 11.1 Les différentes interprétations du Signal

#### Survivants

> Le signal pourrait représenter une possibilité de reconstruction.

#### Bandits

> Le signal pourrait permettre d'obtenir une technologie extrêmement précieuse.

#### Cultistes

> Le signal pourrait être la manifestation de Prométhée.

#### Héritiers de Prométhée

> Le signal semble être associé à un système beaucoup plus ancien et plus complexe que ce que les survivants imaginent.

---

## 12. Évolution des factions

Les factions doivent évoluer avec l'histoire.

Les événements majeurs peuvent provoquer :

* des changements de dirigeants ;
* des alliances ;
* des guerres ;
* des divisions internes ;
* de nouvelles idéologies ;
* des migrations ;
* la création de nouvelles factions.

La chronologie officielle doit être mise à jour lorsque ces événements deviennent canoniques.

Cela permet de conserver la cohérence entre :

* le scénario ;
* les factions ;
* les personnages ;
* les régions ;
* les quêtes ;
* les événements mondiaux.

---

## 13. Secrets et informations cachées

Certaines informations concernant les factions ne doivent pas être révélées immédiatement.

Les joueurs peuvent découvrir progressivement :

* l'origine réelle des Cultistes ;
* les véritables objectifs de Jax ;
* le rôle exact des Survivants dans les événements précédant le jeu ;
* l'origine des Héritiers de Prométhée ;
* les liens entre les factions et les anciennes installations ;
* le véritable rôle de Prométhée ;
* la raison pour laquelle le signal continue d'être transmis.

Ces révélations doivent être intégrées progressivement au scénario.
