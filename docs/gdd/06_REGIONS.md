## 1. 🌍 Présentation

Le monde de **The Last Signal Online** est composé de nombreuses
régions ouvertes que les joueurs peuvent explorer librement.

Chaque région possède une identité propre et contribue à la
construction du monde.

Une région est définie par plusieurs éléments :

* son environnement ;
* son climat ;
* son niveau de contamination ;
* ses ressources ;
* ses dangers ;
* ses créatures ;
* ses lieux importants ;
* son histoire ;
* ses événements ;
* ses anomalies éventuelles.

Les régions doivent donner au joueur l'impression d'explorer un monde
réellement marqué par la catastrophe.

---

## 2. 🎯 Rôle des régions

Les régions servent à structurer le monde ouvert sans empêcher
l'exploration.

Elles permettent notamment de :

* différencier les environnements ;
* organiser la progression du joueur ;
* répartir les ressources ;
* répartir les dangers ;
* raconter l'histoire du monde ;
* placer les villes et autres lieux importants ;
* créer des zones de découverte ;
* proposer différentes expériences d'exploration.

Une région ne doit pas être uniquement une zone géographique.

Elle doit également posséder une **identité narrative et**
**environnementale**.

---

## 4. ☢️ Niveaux de contamination

Les régions sont influencées par leur niveau de contamination.

Ce niveau influence :

* les créatures présentes ;
* la difficulté ;
* les ressources ;
* les récompenses ;
* les risques pour les joueurs.

### 🟢 Zone verte

Les zones vertes sont les régions les plus sûres.

Elles accueillent notamment les principaux camps de survivants et les
nouveaux joueurs.

Les créatures y sont relativement peu nombreuses et faibles.

---

### 🟡 Zone jaune

Les zones jaunes représentent les premières régions contaminées.

Elles proposent davantage de dangers, mais également des ressources
plus intéressantes.

Elles constituent une transition entre les régions sûres et les zones
fortement contaminées.

---

### 🔴 Zone rouge

Les zones rouges sont fortement contaminées.

Les créatures y sont plus nombreuses et plus agressives.

Ces régions nécessitent une meilleure préparation du joueur.

---

### ⚫ Zone noire

Les zones noires représentent les régions les plus fortement
contaminées.

Elles constituent les zones les plus dangereuses du monde.

On peut notamment y trouver :

* des créatures extrêmement dangereuses ;
* des boss majeurs ;
* des laboratoires oubliés ;
* des technologies perdues ;
* des informations importantes sur la catastrophe.

La **Montagne du Dernier Signal** se trouve dans une zone noire.

---

## 5. 🏞️ Types de régions

Les régions peuvent prendre différentes formes.

Exemples :

* villes abandonnées ;
* villages détruits ;
* forêts contaminées ;
* montagnes ;
* laboratoires secrets ;
* bases militaires ;
* usines ;
* marais ;
* grottes ;
* bunkers souterrains.

Une région peut également contenir plusieurs types
d'environnements.

Par exemple, une région montagneuse peut contenir :

* une forêt ;
* un ancien village ;
* une installation scientifique ;
* des grottes ;
* un bunker.

---

## 6. 🧭 Exploration

Le monde est conçu comme un monde ouvert.

Les joueurs peuvent explorer librement les différentes régions.

L'exploration permet de découvrir :

* des ressources ;
* des bâtiments abandonnés ;
* des villes ;
* des villages ;
* des installations scientifiques ;
* des bunkers ;
* des créatures ;
* des documents ;
* des secrets ;
* des anomalies ;
* des signaux radio.

Les régions ne doivent pas toutes révéler immédiatement leurs secrets.

Certaines informations peuvent être découvertes progressivement.

---

## 7. ⛏️ Ressources

Chaque région possède une répartition particulière des ressources.

Les ressources existantes comprennent notamment :

* bois ;
* pierre ;
* métaux ;
* nourriture ;
* composants électroniques ;
* carburant ;
* médicaments.

La disponibilité d'une ressource dépend notamment de
l'environnement et de l'histoire de la région.

Les ressources servent notamment :

* à l'artisanat ;
* aux réparations ;
* aux constructions ;
* au commerce.

---

## 8. ⚠️ Dangers

Chaque région possède ses propres dangers.

Ils peuvent être liés :

* à la contamination ;
* aux créatures ;
* à l'environnement ;
* aux bâtiments abandonnés ;
* aux anomalies ;
* aux événements ;
* à la présence éventuelle de factions.

Le niveau de danger doit être cohérent avec le niveau de contamination
de la région.

---

## 9. 👾 Créatures

Les créatures rencontrées dépendent en partie de la région et de son
niveau de contamination.

Elles peuvent provenir :

* d'humains contaminés ;
* d'animaux mutés ;
* d'expériences scientifiques.

Une région peut posséder une population de créatures particulière.

Les créatures doivent contribuer à l'identité de la région.

---

## 10. 📜 Histoire et narration

Chaque région possède une histoire propre.

Cette histoire peut être racontée par :

* les bâtiments ;
* les ruines ;
* les documents ;
* les survivants ;
* les objets ;
* les traces de la civilisation ;
* les installations scientifiques ;
* les événements ;
* les signaux radio.

L'environnement doit permettre au joueur de comprendre
progressivement ce qui s'est passé.

Les régions peuvent ainsi raconter une partie de l'histoire sans
nécessiter systématiquement une quête.

---

## 11. ⚡ Anomalies

Certaines régions peuvent être affectées par des anomalies.

Les anomalies connues comprennent notamment :

* les tempêtes électromagnétiques ;
* les zones où les communications deviennent impossibles ;
* les perturbations lumineuses ;
* les anomalies gravitationnelles ;
* les champs de contamination instables.

Les anomalies peuvent modifier temporairement le gameplay et créer des
événements imprévisibles.

---

## 12. 🔗 Relations entre les régions

Les régions ne doivent pas être considérées comme des zones totalement
indépendantes.

Elles peuvent être liées par :

* leur géographie ;
* leur histoire ;
* leurs ressources ;
* leurs factions ;
* leurs événements ;
* leurs niveaux de contamination ;
* leurs routes ;
* leurs signaux radio.

Une action réalisée dans une région pourra éventuellement avoir des
conséquences sur une autre région.

Ce système devra être précisé dans les documents consacrés au gameplay
et aux événements.

---

## 15. 🔄 Évolution des régions

Le monde de **The Last Signal Online** est persistant.

Certaines régions pourront donc évoluer au cours du temps.

Une région pourra notamment :

* devenir plus sûre ;
* devenir plus dangereuse ;
* être partiellement reconstruite ;
* être affectée par un événement ;
* voir ses ressources évoluer ;
* être influencée par une faction ;
* être affectée temporairement par une anomalie.

Les possibilités exactes d'évolution seront définies dans les
documents de gameplay correspondants.
