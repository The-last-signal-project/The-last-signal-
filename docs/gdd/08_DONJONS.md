## 1. 🏚️ Présentation

Les donjons sont des lieux d'exploration particuliers présents dans le monde de **The Last Signal Online**.

Ils peuvent être constitués de bâtiments, installations souterraines, complexes abandonnés ou autres lieux présentant un niveau de danger ou d'intérêt supérieur à leur environnement.

Un donjon peut contenir :

* des ressources ;
* des créatures ;
* des objets ;
* des documents ;
* des secrets ;
* des événements ;
* des énigmes ;
* des installations particulières ;
* un ou plusieurs ennemis majeurs.

Les donjons peuvent être liés à l'histoire générale du monde ou simplement proposer des opportunités d'exploration.

---

## 2. 🎯 Rôle des donjons

Les donjons permettent notamment de :

* proposer des zones d'exploration plus complexes ;
* concentrer certains dangers ;
* proposer des récompenses ;
* développer le lore ;
* créer des objectifs d'exploration ;
* introduire certains ennemis ;
* proposer des événements particuliers ;
* mettre le joueur face à des situations différentes de celles rencontrées dans les régions ouvertes.

Un donjon ne doit pas nécessairement être un lieu fermé rempli uniquement de combats.

Il peut également être orienté vers l'exploration, la narration, les énigmes ou la découverte.

---

## 3. 🧩 Types de donjons

Les donjons peuvent avoir différentes formes.

### 🧪 Laboratoire

Ancienne installation scientifique.

Il peut contenir :

* des laboratoires ;
* des archives ;
* du matériel scientifique ;
* des expériences ;
* des informations sur la catastrophe.

---

### 🪖 Installation militaire

Ancienne installation contrôlée ou utilisée par les forces militaires.

Elle peut contenir :

* des équipements ;
* des archives ;
* des zones sécurisées ;
* des infrastructures militaires.

---

### 🏭 Complexe industriel

Ancienne usine ou installation industrielle.

Ces lieux peuvent notamment contenir des matériaux, machines et ressources techniques.

---

### 🕳️ Installation souterraine

Structure située sous la surface.

Elle peut prendre la forme :

* d'un bunker ;
* d'un réseau de tunnels ;
* d'une installation secrète ;
* d'un complexe souterrain.

---

### 🏚️ Bâtiment abandonné

Un bâtiment ordinaire peut devenir un lieu d'exploration important en raison de son histoire, de son contenu ou des dangers qui s'y trouvent.

---

### ☢️ Zone contaminée

Certains donjons peuvent être fortement affectés par la contamination.

Ils peuvent nécessiter une préparation particulière avant leur exploration.

---

## 4. 🧱 Structure d'un donjon

Chaque donjon doit posséder au minimum :

| Élément       | Description                       |
| ------------- | --------------------------------- |
| Identifiant   | Identifiant unique                |

| Région        | Région dans laquelle il se trouve |
| Type          | Type de donjon                    |
| Contamination | Niveau de contamination           |
| Difficulté    | Niveau de difficulté              |
| Entrée        | Point ou méthode d'accès          |
| Ennemis       | Ennemis présents                  |
| Ressources    | Ressources disponibles            |
| Récompenses   | Récompenses possibles             |
| Boss          | Boss éventuel                     |
| Histoire      | Histoire du lieu                  |

---

## 5. 🧭 Exploration

L'exploration d'un donjon peut nécessiter une progression à travers plusieurs zones.

Un donjon peut comporter :

* une entrée ;
* des zones principales ;
* des zones secondaires ;
* des passages cachés ;
* des salles sécurisées ;
* des zones dangereuses ;
* une zone finale.

La structure exacte dépend du type de donjon.

Certains donjons peuvent être linéaires tandis que d'autres peuvent proposer plusieurs chemins.

---

## 6. ⚠️ Dangers

Les dangers d'un donjon peuvent provenir :

* des créatures ;
* de la contamination ;
* de l'environnement ;
* des installations ;
* des anomalies ;
* de pièges ;
* des événements ;
* d'autres joueurs ou factions.

Les dangers doivent être cohérents avec l'histoire et le type du lieu.

---

## 7. 👾 Créatures

Les créatures présentes dans un donjon dépendent notamment :

* de son environnement ;
* de son niveau de contamination ;
* de son histoire ;
* de sa localisation ;
* de son type.

Certains donjons peuvent posséder des créatures particulières qui ne sont pas présentes dans les régions environnantes.

---

## 8. 🎁 Ressources et récompenses

Les donjons peuvent fournir des récompenses aux joueurs.

Ces récompenses peuvent comprendre :

* ressources ;
* matériaux ;
* équipements ;
* objets rares ;
* composants technologiques ;
* informations ;
* documents ;
* objets liés au lore.

La difficulté du donjon doit être cohérente avec l'intérêt de ses récompenses.

---

## 9. 👹 Boss

Certains donjons peuvent posséder un ennemi majeur.

Un boss peut :

* protéger une zone ;
* protéger une ressource ;
* protéger un objet ;
* être lié à l'histoire du lieu ;
* être lié à la contamination ;
* constituer un événement particulier.

Tous les donjons ne doivent pas nécessairement posséder un boss.

---

## 10. 🧠 Énigmes et mécanismes

Certains donjons peuvent utiliser des mécanismes nécessitant autre chose que du combat.

Exemples :

* systèmes électriques ;
* portes verrouillées ;
* systèmes de sécurité ;
* générateurs ;
* consoles ;
* codes ;
* mécanismes environnementaux.

Ces systèmes peuvent nécessiter l'exploration du donjon afin de trouver les informations ou ressources nécessaires.

---

## 11. 📜 Histoire et narration

Les donjons peuvent raconter l'histoire du monde.

Le joueur peut découvrir leur histoire grâce :

* aux documents ;
* aux objets ;
* aux installations ;
* aux archives ;
* aux messages ;
* aux survivants ;
* aux traces laissées dans les lieux ;
* aux événements.

Certains donjons peuvent contenir des informations permettant de mieux comprendre la catastrophe et les événements précédant l'histoire principale.

---

## 12. ☢️ Donjons et contamination

Le niveau de contamination d'un donjon peut influencer :

* les créatures ;
* les dangers ;
* les ressources ;
* les récompenses ;
* les anomalies ;
* les conditions d'exploration.

Un donjon situé dans une zone fortement contaminée peut présenter des conditions différentes d'un donjon situé dans une zone plus sûre.

---

## 13. 🔄 Donjons dynamiques

Certains donjons peuvent évoluer au cours du temps.

Ils peuvent notamment :

* changer d'état ;
* être occupés par une faction ;
* être affectés par un événement ;
* devenir plus ou moins dangereux ;
* voir apparaître ou disparaître certains ennemis ;
* être partiellement détruits ;
* être temporairement accessibles ou inaccessibles.

Les mécanismes exacts de ces évolutions devront être définis dans les documents de gameplay correspondants.
