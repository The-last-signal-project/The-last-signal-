## 1. 📖 Présentation

Les personnages constituent les acteurs du monde de **The Last Signal**.

Ils permettent de représenter les survivants, les communautés, les individus importants et les personnages contrôlés par le jeu, tout en donnant au monde une identité et une histoire.

Chaque personnage doit pouvoir s'intégrer au monde post-apocalyptique présenté dans le document **02_UNIVERS.md**.

Les personnages peuvent avoir leurs propres objectifs, relations, affiliations, connaissances et rôles dans le monde.

---

## 2. 🎯 Rôle des personnages

Les personnages ont plusieurs fonctions dans le jeu :

* participer à la vie du monde ;
* permettre au joueur d'interagir avec l'univers ;
* transmettre des informations ;
* participer aux événements ;
* contribuer à la narration ;
* proposer des services ;
* participer aux échanges économiques ;
* appartenir à des communautés ou factions ;
* donner de la profondeur aux différentes régions ;
* faire évoluer l'histoire du monde.

Les personnages ne doivent pas être uniquement considérés comme des éléments de décor.

---

## 3. 🧩 Catégories de personnages

Les personnages sont répartis en plusieurs catégories générales.

### 3.1 Personnages joueurs

Les personnages joueurs sont contrôlés directement par les joueurs.

Ils peuvent :

* explorer le monde ;
* combattre ;
* commercer ;
* fabriquer des objets ;
* récolter des ressources ;
* rejoindre ou créer des groupes ;
* rejoindre ou créer des guildes ;
* progresser ;
* participer aux événements ;
* interagir avec les autres personnages.

La création détaillée du personnage joueur est définie dans **10_CREATION_PERSONNAGE.md**.

---

### 3.2 Personnages non joueurs

Les personnages non joueurs, ou **PNJ**, sont contrôlés par le jeu.

Ils peuvent notamment être :

* survivants ;
* habitants ;
* marchands ;
* artisans ;
* médecins ;
* informateurs ;
* gardes ;
* personnages liés aux quêtes ;
* personnages liés aux événements ;
* personnages hostiles.

Leur comportement dépend de leur rôle et du contexte dans lequel ils se trouvent.

---

### 3.3 Personnages importants

Certains personnages possèdent une importance particulière dans l'univers.

Ils peuvent être liés :

* à l'histoire principale ;
* à une région ;
* à une ville ;
* à une faction ;
* à une quête ;
* à un événement ;
* à un lieu particulier ;
* aux mystères du monde.

Ces personnages peuvent posséder une histoire plus développée et des relations particulières avec d'autres personnages.

---

## 4. 🧑 Personnages joueurs

Le personnage joueur représente l'identité du joueur dans le monde de **The Last Signal**.

Il évolue au cours de son aventure et peut développer différentes compétences, statistiques, métiers et spécialisations.

La progression du personnage est définie dans les documents consacrés à la progression, aux statistiques, aux compétences, aux classes et aux métiers.

Le personnage joueur doit pouvoir s'intégrer au monde sans être séparé de celui-ci.

---

## 5. 🤝 Personnages non joueurs

Les PNJ permettent de rendre le monde vivant.

Un PNJ peut avoir :

* un rôle ;
* un emplacement ;
* une activité ;
* des relations ;
* une affiliation ;
* des connaissances ;
* des services ;
* des objectifs ;
* un comportement.

Certains PNJ peuvent rester associés à un lieu précis tandis que d'autres peuvent être amenés à se déplacer selon les systèmes du jeu.

---

## 6. ⭐ Personnages importants

Les personnages importants doivent posséder une identité et une fonction clairement définies.

Ils peuvent servir à :

* faire progresser une intrigue ;
* révéler des informations ;
* introduire une région ;
* présenter une communauté ;
* transmettre des connaissances ;
* déclencher une quête ;
* participer à un événement ;
* conserver des informations importantes sur le monde.

Leur présence doit avoir une justification dans l'univers.

---

## 7. 🪪 Identité et caractéristiques

Chaque personnage peut posséder différentes informations permettant de l'identifier.

### Informations générales

* Identifiant unique ;
* nom ;
* prénom ou appellation ;
* catégorie ;
* rôle ;
* origine ;
* lieu d'origine ;
* lieu actuel ;
* affiliation éventuelle.

### Caractéristiques supplémentaires

Selon son importance, un personnage peut également posséder :

* une histoire ;
* des objectifs ;
* des connaissances ;
* des relations ;
* des compétences ;
* des services ;
* des dialogues ;
* des informations spécifiques.

Les caractéristiques techniques précises seront définies dans les systèmes correspondants.

---

## 8. 🧠 Personnalité et comportement

Les personnages doivent pouvoir être différenciés par leur personnalité et leur comportement.

Le comportement peut dépendre :

* du rôle du personnage ;
* de son environnement ;
* de sa situation ;
* de ses relations ;
* de son affiliation ;
* des événements du monde ;
* des interactions avec les joueurs.

Un personnage peut par exemple être :

* accueillant ;
* méfiant ;
* neutre ;
* hostile ;
* coopératif ;
* opportuniste ;
* protecteur.

Ces caractéristiques servent principalement à définir la cohérence du personnage et ses interactions avec le monde.

---

## 9. 🔗 Relations

Les personnages peuvent entretenir des relations entre eux et avec les joueurs.

Une relation peut représenter :

* la confiance ;
* l'amitié ;
* la méfiance ;
* la coopération ;
* l'hostilité ;
* une dette ;
* une alliance ;
* une appartenance commune.

Les relations peuvent évoluer en fonction des actions réalisées dans le monde.

Elles peuvent également influencer certaines interactions.

---

## 10. 🏴 Factions et affiliations

Un personnage peut être associé à une faction ou à une communauté.

Cette affiliation peut avoir une influence sur :

* ses relations ;
* ses interactions ;
* ses objectifs ;
* ses services ;
* son comportement ;
* son rôle dans certaines situations.

Les factions sont définies dans **05_FACTIONS.md**.

Aucune affiliation ne doit être ajoutée à un personnage sans cohérence avec l'histoire et l'univers.

---

## 11. 🌍 Rôle dans l'univers

Chaque personnage doit avoir une place cohérente dans le monde.

Son existence peut être liée :

* à une ville ;
* à une région ;
* à un donjon ;
* à une faction ;
* à une activité ;
* à une histoire personnelle ;
* à un événement ;
* à une quête.

Les personnages peuvent également contribuer à raconter indirectement l'histoire du monde.

Leur présence, leurs dialogues et leurs actions peuvent donner des informations sur les événements passés et actuels.

---

## 12. 🔄 Évolution des personnages

Certains personnages peuvent évoluer au cours du jeu.

Cette évolution peut concerner :

* leur position ;
* leurs relations ;
* leur comportement ;
* leurs objectifs ;
* leur lieu de résidence ;
* leur rôle ;
* leur disponibilité ;
* leur situation dans le monde.

L'évolution doit rester cohérente avec les événements du monde persistant.

---

## 13. 📜 Personnages et narration

Les personnages constituent un élément important de la narration de **The Last Signal**.

Ils peuvent permettre au joueur de découvrir :

* l'histoire du monde ;
* les conséquences de la catastrophe ;
* les événements passés ;
* les communautés survivantes ;
* les lieux importants ;
* les mystères du monde ;
* les recherches scientifiques ;
* les informations liées au Dernier Signal.

La narration ne doit cependant pas dépendre exclusivement des personnages.

L'environnement, les bâtiments, les documents, les objets et les lieux peuvent également raconter l'histoire du monde.
