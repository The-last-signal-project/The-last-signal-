## 1. 📖 Présentation

La progression représente l'évolution du personnage au cours de son aventure dans **The Last Signal**.

Elle permet au joueur de développer progressivement son personnage grâce à ses activités, ses découvertes, ses combats, ses compétences, ses métiers et ses interactions avec le monde.

La progression doit encourager l'exploration et la découverte sans réduire le jeu à une simple accumulation de niveaux.

---

## 2. 🎯 Objectifs

Le système de progression doit permettre de :

* donner un sentiment d'évolution au joueur ;
* récompenser les activités réalisées dans le monde ;
* permettre différentes orientations de personnage ;
* encourager l'exploration ;
* permettre la spécialisation ;
* conserver une progression compréhensible ;
* éviter qu'une seule activité soit systématiquement optimale ;
* maintenir l'intérêt du jeu sur le long terme.

La progression doit rester cohérente avec le monde persistant.

---

## 3. 🧭 Principes de progression

La progression repose sur plusieurs principes.

### Progression progressive

Le personnage évolue progressivement au lieu d'obtenir immédiatement toutes ses capacités.

### Diversité

Plusieurs activités doivent pouvoir contribuer à la progression.

### Spécialisation

Les choix du joueur peuvent orienter son personnage vers certains domaines.

### Conséquences

La progression doit avoir des conséquences concrètes sur les possibilités du personnage.

### Liberté

Le joueur doit pouvoir développer son personnage selon son style de jeu.

---

## 4. 📊 Niveau du personnage

Le personnage possède un niveau représentant son évolution générale.

Le niveau peut être utilisé pour :

* débloquer certaines possibilités ;
* accéder à certains équipements ;
* accéder à certaines compétences ;
* déterminer certaines limites ;
* représenter l'avancement général du personnage.

Le niveau maximal doit être défini par le système de progression.

> **Niveau maximum :** À définir.

Le niveau ne doit pas remplacer les autres systèmes de progression.

---

## 5. ⭐ Expérience

L'expérience permet de mesurer la progression du personnage vers le niveau suivant.

Lorsqu'un personnage atteint suffisamment d'expérience, il peut progresser d'un niveau.

### Données principales

* expérience actuelle ;
* expérience nécessaire pour le niveau suivant ;
* niveau actuel ;
* expérience totale éventuellement conservée.

La formule d'expérience devra être définie séparément lors de l'équilibrage.

> **Formule d'expérience :** À définir.

---

## 6. 🎯 Sources d'expérience

L'expérience peut provenir de différentes activités.

Selon les systèmes du jeu, elle peut notamment être obtenue grâce à :

* combats ;
* quêtes ;
* exploration ;
* découverte de lieux ;
* événements ;
* activités liées aux métiers ;
* accomplissement d'objectifs ;
* activités de groupe ;
* contenu PvE ;
* contenu PvP lorsque le système le prévoit.

Les récompenses doivent être équilibrées afin d'éviter qu'une seule activité domine toutes les autres.

---

## 7. 🪜 Paliers de progression

La progression peut être organisée en différents paliers.

| Palier        |    Niveau | Description                             |
| ------------- | --------: | --------------------------------------- |
| Débutant      | À définir | Découverte des systèmes de base         |
| Intermédiaire | À définir | Accès à davantage de possibilités       |
| Avancé        | À définir | Personnage spécialisé                   |
| Expert        | À définir | Maîtrise avancée                        |
| Endgame       | À définir | Contenu destiné aux personnages avancés |

Les noms et limites définitifs restent à définir.

---

## 8. 🎁 Récompenses de progression

La montée en niveau peut permettre d'obtenir différentes récompenses.

Selon les systèmes concernés, celles-ci peuvent comprendre :

* accès à de nouvelles compétences ;
* amélioration de certaines possibilités ;
* accès à de nouveaux équipements ;
* déblocage de contenu ;
* points permettant de développer le personnage ;
* accès à certains objets ou systèmes.

Les récompenses doivent être cohérentes avec le niveau et le type de progression concerné.

---

## 9. 📊 Statistiques et progression

Les statistiques représentent certaines caractéristiques du personnage.

La progression peut permettre de faire évoluer ces statistiques selon les règles définies dans **12_STATISTIQUES.md**.

Le système de progression ne doit pas définir directement toutes les statistiques.

Il doit plutôt déterminer :

* quand elles peuvent évoluer ;
* comment les points sont obtenus, si ce système est retenu ;
* quelles limites s'appliquent ;
* comment la progression générale interagit avec elles.

---

## 10. 🧠 Compétences et progression

Les compétences permettent au personnage de développer des capacités particulières.

La progression peut débloquer :

* de nouvelles compétences ;
* de nouveaux niveaux de compétence ;
* des améliorations ;
* des spécialisations.

Le fonctionnement détaillé est défini dans **13_COMPETENCES.md**.

Le système doit éviter que le niveau général du personnage rende automatiquement toutes les compétences disponibles.

---

## 11. 🛡️ Classes et progression

Les classes représentent des orientations possibles du personnage.

La progression peut permettre :

* de débloquer une classe ;
* de développer une classe ;
* d'accéder à des spécialisations ;
* de faire évoluer les possibilités liées à une classe.

Les règles détaillées sont définies dans **14_CLASSES.md**.

Les classes ne doivent pas nécessairement déterminer entièrement le personnage.

---

## 12. 🔨 Métiers et progression

Les métiers constituent une autre forme de progression.

Un personnage peut développer ses connaissances et son efficacité dans différents métiers.

La progression des métiers doit être distincte du niveau général du personnage lorsque cela est pertinent.

Elle peut notamment dépendre :

* de la pratique ;
* de la fabrication ;
* de la récolte ;
* de l'utilisation de recettes ;
* de l'acquisition de connaissances.

Les règles détaillées sont définies dans **29_METIERS.md**.

---

## 13. 🔄 Progression horizontale

La progression ne doit pas être uniquement verticale.

La progression horizontale permet au joueur d'obtenir davantage de possibilités sans nécessairement devenir directement plus puissant.

Elle peut prendre la forme de :

* nouvelles compétences ;
* nouvelles recettes ;
* nouvelles connaissances ;
* nouvelles possibilités de fabrication ;
* nouveaux métiers ;
* nouvelles interactions ;
* nouveaux accès ;
* nouvelles options de gameplay.

Cette approche permet de différencier deux personnages de niveau similaire.

---

## 14. 🚧 Limites de progression

Le système doit prévoir certaines limites afin de conserver un équilibre.

Ces limites peuvent concerner :

* le niveau maximal ;
* les compétences accessibles ;
* les statistiques ;
* les classes ;
* les métiers ;
* certains équipements ;
* certains contenus.

Certaines restrictions peuvent dépendre du niveau tandis que d'autres peuvent dépendre d'une compétence, d'un métier, d'une classe ou d'une condition particulière.

---

## 15. 🔄 Réinitialisation et modifications

Certaines caractéristiques du personnage peuvent éventuellement être modifiables après leur acquisition.

Les règles doivent préciser :

* ce qui peut être modifié ;
* ce qui peut être réinitialisé ;
* le coût éventuel ;
* les conditions nécessaires ;
* les éléments définitivement acquis.

> **Système de réinitialisation :** À définir.

Toute modification doit être contrôlée par le serveur.

---

## 16. 📋 Suivi de la progression

Le joueur doit pouvoir consulter sa progression.

L'interface peut afficher :

* niveau actuel ;
* expérience actuelle ;
* expérience nécessaire ;
* progression vers le niveau suivant ;
* compétences disponibles ;
* points disponibles ;
* progression des métiers ;
* informations sur les prochaines étapes.

Ces informations devront être intégrées au HUD et aux menus du jeu.
