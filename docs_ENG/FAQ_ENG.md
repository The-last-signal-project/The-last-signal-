# ❓ FAQ — The Last Signal Online

This FAQ answers the most frequently asked questions about the project,
its development, and contribution.

---

## 🎮 About the Project

### 1. What is The Last Signal Online?

**The Last Signal Online** is a post-apocalyptic survival MMORPG
set in a persistent world.

Players will explore the world, survive, cooperate or compete with each other,
develop their characters, and gradually discover the world's secrets
and the origin of the last signal.

For more information:
➡️ [Game Design Document](gdd/)

---

### 2. What is the current state of the project?

The project is currently in the **prototype and development phase**.

The Rust server, Python client, networking system, and several
documentation components are currently under development.

Some features planned in the Game Design Document have
therefore not yet been implemented.

➡️ See the [roadmap](ROADMAP_ENG.md) to follow the project's progress.

---

### 3. Is the game currently playable?

The project already has functional components on both the client
and server sides, but the complete game is not yet available
in its final version.

Development is progressing gradually, starting with the
technical foundations of the game.

---

## 🛠️ Development

### 4. What technologies are used to develop the game?

The project primarily uses:

* 🦀 **Rust** for the server
* 🐍 **Python** for the client
* 🗄️ **SQLite** for the current database
* 🌐 A client/server communication system
* ⚙️ **GitHub Actions** for continuous integration and automated testing

Other technologies may be added as development progresses.

---

### 5. Why use Rust for the server and Python for the client?

Rust is used for the server to provide strong performance,
memory safety, and a solid foundation for a multiplayer server.

Python is used for the client to facilitate development,
prototyping, and the creation of the various client systems.

This separation also allows the client and server
to evolve independently.

### 11. How do I make my first Pull Request?

The general process is:

1. Choose an Issue.
2. Read the information and requirements of the Issue.
3. Create a dedicated branch.
4. Make your changes.
5. Test your changes.
6. Create a clear commit.
7. Push your branch to GitHub.
8. Open a Pull Request.

➡️ For a first contribution, see
[New Contributor? Start Here!](https://github.com/DDCoder23/The-last-signal-/issues/97).
