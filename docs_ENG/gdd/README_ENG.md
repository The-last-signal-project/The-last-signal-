# 🎮 Game Design Document (GDD)

> Game design documentation for **The Last Signal Online**

The **Game Design Document (GDD)** outlines all game mechanics, worldbuilding lore, and systems for **The Last Signal Online**.

It serves as the primary technical and creative reference for all project team members.
