## 🎮 プロジェクトについて

### 1. The Last Signal Online とは何（なん）ですか？

**The Last Signal Online** は、持続（じぞく）する世界（せかい）を舞台（ぶたい）にした、
終末（しゅうまつ）世界（せかい）のサバイバル MMORPG です。

プレイヤーは世界（せかい）を探索（たんさく）し、生存（せいぞん）し、
協力（きょうりょく）したり対立（たいりつ）したりしながら、
自分（じぶん）のキャラクターを成長（せいちょう）させ、
世界（せかい）の秘密（ひみつ）や最後（さいご）の信号（しんごう）の起源（きげん）を
少（すこ）しずつ発見（はっけん）していきます。

詳（くわ）しい情報（じょうほう）：
➡️ [Game Design Document](gdd/)

---

### 2. 現在（げんざい）のプロジェクトの状態（じょうたい）はどうなっていますか？

現在（げんざい）、プロジェクトは**プロトタイプおよび開発（かいはつ）段階（だんかい）**です。

Rust サーバー、Python クライアント、ネットワークシステム、
そして複数（ふくすう）のドキュメントが現在（げんざい）開発（かいはつ）中（ちゅう）です。

そのため、Game Design Document に予定（よてい）されている機能（きのう）の一部（いちぶ）は、
まだ実装（じっそう）されていません。

➡️ プロジェクトの進捗（しんちょく）については
[Roadmap](ROADMAP_JP.md) を参照（さんしょう）してください。

---

### 3. 現在（げんざい）、ゲームをプレイできますか？

プロジェクトには、クライアントとサーバーの両方（りょうほう）に
すでに動作（どうさ）する部分（ぶぶん）がありますが、
完全（かんぜん）なゲームはまだ最終（さいしゅう）版（ばん）として
公開（こうかい）されていません。

開発（かいはつ）は、ゲームの技術（ぎじゅつ）的（てき）な基盤（きばん）から
段階（だんかい）的（てき）に進（すす）められています。

## 🛠️ 開発（かいはつ）

### 4. ゲームの開発（かいはつ）にはどのような技術（ぎじゅつ）が使（つか）われていますか？

プロジェクトでは主（おも）に以下（いか）の技術（ぎじゅつ）を使用（しよう）しています：

* 🦀 **Rust** — サーバー
* 🐍 **Python** — クライアント
* 🗄️ **SQLite** — 現在（げんざい）のデータベース
* 🌐 クライアントとサーバーの通信（つうしん）システム
* ⚙️ **GitHub Actions** — 継続（けいぞく）的（てき）インテグレーションと自動（じどう）テスト

開発（かいはつ）の進展（しんてん）に応（おう）じて、
ほかの技術（ぎじゅつ）が追加（ついか）される場合（ばあい）があります。

### 5. なぜサーバーに Rust、クライアントに Python を使（つか）っているのですか？

Rust は、高（たか）い性能（せいのう）、メモリ安全性（あんぜんせい）、
そしてマルチプレイヤーサーバーのための安定（あんてい）した基盤（きばん）を
提供（ていきょう）するため、サーバーに使用（しよう）されています。

Python は、開発（かいはつ）、プロトタイピング、
そしてクライアントの各（かく）システムの作成（さくせい）を
容易（ようい）にするため、クライアントに使用（しよう）されています。

この分離（ぶんり）によって、クライアントとサーバーを
それぞれ独立（どくりつ）して発展（はってん）させることもできます。

2. Issue の情報（じょうほう）と要件（ようけん）を読（よ）みます。
3. 専用（せんよう）のブランチを作成（さくせい）します。

6. 分（わ）かりやすいコミットを作成（さくせい）します。
7. ブランチを GitHub にプッシュします。
8. Pull Request を作成（さくせい）します。
